YASH TRADE APP — DEMO LOGIN CREDENTIALS
========================================
DEVELOPMENT & STAGING ONLY. No production credentials or secrets belong in this file.

HOW LOGIN WORKS
---------------
- EVERYONE uses the SAME login screen (phone number + 4-digit OTP).
- There is no role selector: the BACKEND role attached to the phone number
  decides which experience opens after OTP verification.
- Only REGISTERED numbers can log in. Unknown numbers see a
  "Registration required" message pointing to the Yash Ornaments enrollment website.
- Inactive accounts are blocked from logging in and from all protected APIs.

NOTES
-----
- "Telecaller" is displayed in the UI; the canonical backend role is `executive`.
- The demo OTP 1234 works ONLY for the phones listed in the OTP_DEMO_PHONES
  environment variable (backend/.env). Every other number receives a REAL SMS
  via MSG91.
- To fully disable demo logins in production, remove the demo phones from
  OTP_DEMO_PHONES and keep OTP_DEMO_MODE=false.
- Unknown-number test: enter any unregistered number (e.g. 9876501234) on the
  login screen — the app must show "Registration required" with an enroll link
  and must NOT create an account.
